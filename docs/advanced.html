Wire Protocol Specification

The communication between client and server is strictly orchestrated to ensure high availability and correctness.

1. Chunk Handshake Headers

Header Required Purpose
X-Upload-Session-ID Yes Traces chunks to a unified session.
X-Upload-Chunk-Index Yes Current slice index (base-0).
X-Upload-Total-Chunks Yes Total planned slices for the file.

2. Termination Signal

When `chunkIndex + 1 === totalChunks`, the server triggers the **StorageReassembly** logic.

"Reassembly is O(n) where n is total size. Use NVMe disks for temporary staging to avoid timeouts."

Security Architecture

Metadata Verification

Servers re-validate MIME types on the final compiled file to prevent extension smuggling.

Atomic Cleanup

If a file is rejected during finalization, all partial chunks are immediately purged from Disk/S3.
