System Error Registry

A comprehensive guide to interpreting API response codes and worker error signals.

Error Code HTTP Stat Origination Resolution Path
ERR_INVALID_MIME 415 Server Engine The file magic bytes do not match the expected media kind. Block the upload.
ERR_SIZE_EXCEEDED 413 Server Validator File payload exceeds the limits defined in UploadTypeConfig.
ERR_CHUNK_MISMATCH 400 Server Reassembler The hashes of reassembled chunks do not match the total file hash. Trigger manual retry.
ERR_WASM_MEM_LIMIT N/A Client Worker WASM FFmpeg ran out of memory. Reduce the processing quality to low.
ERR_IDB_QUOTA_FULL N/A Client Browser IndexedDB storage is full. Call manager.clear('completed').
ERR_AUTH_EXPIRED 401 Adapter Wrapper Refresh the session token using the onBackground auth hook.

The Kernel: Internal Flow Control

Understanding the UploadEngine internals is key for contributing. The following diagram and method list describe the execution order during a Chunked Multipart Request.

Execution Lifecycle

Adapter.wrap() Normalizes Request -> IncomingMessage bridge.
Engine.handle() Initializes the Busboy derivative parser.
onField() Parses protocol fields (sessionId, chunkIndex).
onFile() Streams raw binary directly into the StorageAdapter.
finalize() Only called if currentChunk + 1 === totalChunks.

Core Kernel Methods (private/protected)

Method Name Role Critical Logic
#parseMultipart() Primary Slicer Splits the raw buffer based on current boundary. Emits 'field' and 'file' events.
#validateChunk() Boundary Guard Ensures the chunk size matches the planned offset to prevent data corruption.
#resolveStorage() Provider Router Selects the correct adapter based on UploadTypeConfig.
#runBackground() Post-Response Triggers after the HTTP socket closes. Handles database persistence.

UploadEngine Class

The primary interface for file uploads. It orchestrates the parsing, validation, and storage logic.

Method Signature Returns Description
constructor (config: UploadEngineConfig) - Initializes the engine with configuration and storage adapters.
handle req: NormalizedRequest, res: NormalizedResponse, opts?: Overrides Promise<Result> The central processing hub. Resolves on chunk completion or final finalization.
cleanup() files: FileRecord | FileRecord[] Promise<void> Forcefully removes binaries from storage and metadata from repo.
deleteFiles() ids: string[] Promise<number> Bulk deletion logic by unique identifiers.
getRepo() - MetadataRepository Getter for the underlying persistence adapter.

CONFIG (UploadEngineConfig)

Property Type Required Description
storages Record<string, StorageAdapter> Yes Mapping of storage providers.
database MetadataRepository Yes Persistence engine for file records.
uploadTypes Record<string, UploadTypeConfig> Yes Validation and processing rules.
defaultStorage string Yes Fall-back storage key.

UploadManager Class

Method Arguments Returns Description
upload() blobs: File[], fieldnames?: string[], options: Params void Queues files for processing. Fieldnames map 1:1 with blobs.
pause() id: string void Emergency halt of all network requests for a session.
resume() id: string void Calculates delta and restarts the chunk loop.
cancel() id: string void Complete purge of local state and assets.

Interface Definitions

                    export interface FileRecord {
                        id: string;            // Unique ID generated by the repository
                        originalName: string;  // Name of the file on the user's disk
                        storedName: string;    // Name of the file in the storage bucket
                        contentType: string;   // Verified MIME type
                        size: number;          // Total bytes
                        url: string;           // Full accessibility URL
                        storageProvider: string; // Key of the storage adapter used
                        storageRef: string;    // Internal path used by the adapter
                        createdAt: Date;       // ISO timestamp
                        metadata?: Record<string, any>; // Custom fields passed during init
                        thumbnailUrl?: string; // URL to the generated JPEG preview
                        qualities?: Record<string, string>; // Multi-quality variants (high, med, low)
                    }

                    export interface UploadTypeConfig {
                        allowedKinds: ('image' | 'video' | 'audio' | 'document')[];
                        limits: { [key in MediaKind]?: number };
                        thumbnails?: boolean;
                        quality?: 'low' | 'medium' | 'high';
                        storage?: string; // Override default storage
                    }
