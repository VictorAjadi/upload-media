Client-Side Manual

Worker-powered upload orchestration, state management, and browser-side media processing.

Pure HTML & Vanilla JS

Zero frameworks needed. Use CDN import maps to resolve all dependencies directly in the browser.

index.html (Complete Working Example)
<!DOCTYPE html>
<html>
<head>
  <!-- CDN Import Map -->
  <script type="importmap">
  {
    "imports": {
      "@upload-media/client": "https://unpkg.com/@upload-media/client@latest/dist/index.mjs",
      "zustand/vanilla": "https://unpkg.com/zustand@latest/esm/vanilla.mjs",
      "zustand/middleware": "https://unpkg.com/zustand@latest/esm/middleware.mjs",
      "immer": "https://unpkg.com/immer@latest/dist/immer.mjs",
      "@ffmpeg/ffmpeg": "https://unpkg.com/@ffmpeg/ffmpeg@latest/dist/esm/index.js",
      "@ffmpeg/util": "https://unpkg.com/@ffmpeg/util@latest/dist/esm/index.js"
    }
  }
  </script>
</head>
<body>
  <input type="file" id="fileInput" multiple />
  <button id="uploadBtn">Upload</button>
  <div id="progress"></div>

  <script type="module">
    import { UploadManager, useUploadProgress } from '@upload-media/client';

    const manager = new UploadManager({
      workerUrl: '/upload.worker.js'
    });

    document.getElementById('uploadBtn').addEventListener('click', () => {
      const files = Array.from(document.getElementById('fileInput').files);
      if (!files.length) return;

      manager.upload(files, ['video'], {
        uploadId: `session_${Date.now()}`,
        endpoint: '/api/upload'
      });
    });

    useUploadProgress.subscribe((state) => {
      document.getElementById('progress').innerHTML =
        state.uploads.map(u => `
          <div>
            <p>${u.uploadId}: ${u.overallProgress}%</p>
            <progress value="${u.overallProgress}" max="100"></progress>
          </div>
        `).join('');
    });
  </script>
</body>
</html>

Upload Actions API

initializeUpload Payload

Key Type Required Description
uploadId string Yes Unique session identifier.
blobs File[] Yes Array of File/Blob objects.
endpoint string Yes Server URL for chunk ingestion.
metadata Config[] No Maps blobs to fieldname keys.
postData Record No Extra form fields sent with every chunk.
transform boolean No Enable WASM video processing pipeline.
videoStartTime number No Trim start (seconds). Requires transform: true.
videoEndTime number No Trim end (seconds). Requires transform: true.
transformer object No Transformation config (quality, qualities, format).
transformer.qualities array No Generate multiple variants. e.g. ['high', 'medium', 'low']

Available Methods

Method Arguments Description
initializeUpload() UploadPayload Start a new upload or resume an interrupted one.
pauseUpload() uploadId: string Halt all active network requests for the session.
resumeUpload() uploadId: string Re-trigger the worker chunk loop from last checkpoint.
cancelUpload() uploadId: string Terminate session and purge its IndexedDB data.
clearUploads() type: string Remove 'completed' or 'failed' uploads from state.
getUpload() uploadId: string Retrieve a specific upload session by ID.
totalProgress getter Average overall progress across all active sessions.
activeUploads getter Total count of uploads currently in progress.

React Hook Usage

import { useUploadActions, useUploadProgress } from '@upload-media/client';

const { initializeUpload, pauseUpload, resumeUpload, cancelUpload } = useUploadActions();
const uploads = useUploadProgress(s => s.uploads);

// Resume a previously interrupted session
resumeUpload('session_abc123');

Advanced WASM Tools (FFmpeg)

Trim and process media in-browser before upload. Reduces server load and improves UX. ⚠️ Requires Cross-Origin Isolation (COOP/COEP) headers.

Video & Audio Trimmers

import { useVideoTrimmer, useAudioTrimmer } from '@upload-media/client';

// 1. Video Trimming
const { trimVideo } = useVideoTrimmer();
const video = await trimVideo(file, { 
  startTime: 10, 
  endTime: 60, 
  quality: 'high' 
});

// 2. Audio Trimming
const { trimAudio } = useAudioTrimmer();
const audio = await trimAudio(file, {
  startTime: 0,
  endTime: 30,
  quality: 'medium'
});

One-Pass Processing

initializeUpload({
  blobs: [videoFile],
  transform: true,
  videoStartTime: 10,
  videoEndTime: 60,
  quality: 'medium',
  endpoint: '/api/upload'
});

The internal engine automatically selects the correct trimmer based on file MIME type.

Transformation Hooks

The transformation pipeline is fully extensible. You can inject custom logic like watermarking or document encryption before the upload starts.

Custom File Mutator 

setUploadMediaConfig({
  hooks: {
    beforeProcess: async (file) => {
      // Example: Adding a Watermark Layer
      if (file.type.startsWith('image/')) {
        return await applyWatermark(file, '© 2026');
      }
      return file;
    }
  }
});

The State Engine

A reactive Zustand store powered by Immer for zero-allocation state updates.

Property Type Description
uploads UploadSession[] Active and historical sessions.
overallProgress number Weighted total completion (0-100).
speed number Current throughput in Bytes/sec.
status string 'uploading' | 'paused' | 'failed' | 'completed'.

Global Configuration

Override engine behavior for all upload sessions via setUploadMediaConfig().

import { setUploadMediaConfig } from '@upload-media/client';

setUploadMediaConfig({
  maxConcurrent: 5,
  maxRetries: 10,
  chunkSizes: {
    video: 5 * 1024 * 1024,   // 5MB for videos
    image: 1 * 1024 * 1024,   // 1MB for images
    default: 2 * 1024 * 1024  // 2MB fallback
  }
});
